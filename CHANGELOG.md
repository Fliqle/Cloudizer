# Changelog

## [1.7.0] - 2026-10-27

### Added

- Сохранение GIF-файлов в исходном формате, включая ссылки без расширения.
- Создание, переименование и удаление категорий через компактные теги.

### Changed

- Страница настроек переработана по новому макету.
- Интерфейс приведён к единой сетке отступов и получил собственные SVG-иконки.

## [1.6.0] - 2026-10-14

### Added

- Выбор места сохранения: Облако Mail или локальная папка «Загрузки».
- Локальное сохранение с той же структурой основной папки и категорий.

### Fixed

- Атомарное разрешение совпадающих имён без перезаписи файлов.
- Удалена небезопасная связка `HEAD` + `PUT`; исправлена обработка `MKCOL`.
- Порог 100×100 теперь считается по отображаемому размеру изображения.
- Выключение расширения сразу скрывает кнопку и меню.
- Проверка типа ответа перед загрузкой в облако.
- Исправлена инструкция установки расширения.

## [1.5.0] - 2026-08-10

### Changed

- Порог минимального размера картинки для показа кнопки при наведении увеличен
  с 64×64 до 100×100 px.
- Порог теперь считается по фактическому отображаемому размеру картинки на
  странице, а не по размеру самого файла. Раньше крупный исходный файл,
  показанный на странице маленьким превью, ошибочно проходил проверку и
  кнопка всё равно появлялась.
- Пункт контекстного меню («Сохранить в Облако» по правому клику) на это
  ограничение не влияет и остаётся доступен для картинок любого размера.
