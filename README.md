# Сохранить картинку в Облако Mail — расширение Chrome

Наводите курсор на любую картинку на сайте и нажмите появившуюся иконку — изображение
загрузится в ваше Облако Mail (по WebDAV) в выбранную папку.

## Установка (режим разработчика)

1. Скачайте репозиторий с расширением на свой компьютер
2. Откройте `chrome://extensions`.
3. Включите **«Режим разработчика»** (тумблер справа сверху).
4. Нажмите **«Загрузить распакованное расширение»** и выберите папку `Cloudizer/src`.

## Настройка

1. Откройте настройки расширения (иконка расширения → «Открыть настройки»).
2. Введите:
   - **E-mail Mail.ru** — полный адрес, например `example@mail.ru`.
   - **Пароль для внешнего приложения** — НЕ основной пароль почты. Создаётся в
     настройках Mail ID → «Пароли для внешних приложений» (нужен привязанный телефон).
   - **Папка в Облаке** — основная папка (создастся автоматически).
   - **Категории** — список подпапок (по одной в строке), по умолчанию:
     Интерьер, Фото, Арт, Интерфейс.
3. Нажмите **«Проверить подключение»**, затем **«Сохранить»**.

> ⚠️ **WebDAV у Облака Mail работает только на платных тарифах.** На бесплатном аккаунте
> загрузка не сработает (проверка подключения покажет отказ доступа).

## Как пользоваться

Наведите мышь на картинку → в правом верхнем углу появится иконка облака →
кликните по ней → выберите категорию в меню. Картинка ляжет в подпапку категории
внутри основной папки (например `Сохранённые картинки/Интерьер`).

## Структура

| Файл | Назначение |
|------|------------|
| `manifest.json` | Манифест MV3 |
| `src/content.js` / `content.css` | Иконка на картинках при наведении (в Shadow DOM) |
| `icons/hover.svg` | Иконка на картинке при наведении — **можно редактировать** |
| `icons/success.svg` / `error.svg` | Иконки результата (успех/ошибка) — **можно редактировать** |
| `src/background.js` | Service worker: скачивание картинки и загрузка в Облако |
| `src/webdav.js` | WebDAV-клиент (MKCOL/HEAD/PUT/PROPFIND, Basic-auth) |
| `src/util.js` | Настройки, имена файлов |
| `src/options.*` | Страница настроек |
| `src/popup.*` | Всплывающее окно (вкл/выкл, статус) |
| `generate-icons.js` | Генератор PNG-иконок (запускать не обязательно) |

## Технические заметки

- Весь интерфейс плагина живёт в **Shadow DOM**, поэтому CSS сайта не ломает кнопку и меню.
- Иконки на странице — обычные SVG в папке `icons/` (`hover.svg`, `success.svg`,
  `error.svg`). Меняйте их как хотите; цвет берётся из CSS (`currentColor`).
- Все сетевые запросы (скачивание картинок с любых сайтов и WebDAV) выполняются в
  service worker — там `host_permissions: <all_urls>` снимают ограничения CORS.
- При совпадении имён файл получает суффикс ` (1)`, ` (2)`…
- Картинки меньше 100×100 px (по фактическому отображаемому размеру на странице)
  не помечаются кнопкой при наведении. В контекстном меню («Сохранить в Облако»
  по правому клику) пункт доступен всегда, независимо от размера.
- Некоторые картинки, требующие авторизации/referrer исходного сайта, могут не
  скачаться — будет показана ошибка, расширение не падает.
